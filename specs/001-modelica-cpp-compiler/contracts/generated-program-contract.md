# 契约: 生成程序的行为

## 构建要求

- 生成的工程目录 MUST 可用标准 CMake ≥3.24 + C++20 编译器一次性构建成功，
  无需人工修改（FR-002）。
- v1 零第三方依赖（仅标准库）；未来引入开源数学库时 MUST 固定版本并在
  生成工程的 CMakeLists 注释中声明来源版本（FR-002 政策）。

## 运行行为

| 项 | 契约 |
|----|------|
| 命令行参数 | 无（FR-003）；任何参数被忽略或打印提示后退出 |
| 时间网格 | `[StartTime, StopTime]`，等分 `round((StopTime-StartTime)/Interval)` 步 |
| 积分方法 | 固定步长经典 RK4（research R4），逐位确定 |
| 输出文件 | 当前工作目录下 `<model名>_result.csv` |
| 输出时机 | 每个网格点（含 t=StartTime 与 t=StopTime）写一行 |
| 成功退出 | 0，stderr 无输出 |
| 数值发散 | 检测到非有限值时：stderr 打印含当前时间的提示，删除半成品 CSV 后以退出码 3 终止（spec 边缘用例：发散必须有明确提示） |

## 可溯源要求（FR-008）

- 生成的 C++ 中变量名与源模型一致（保留字冲突加后缀 `_` 并附注释注明原名）。
- 文件头注释块包含源模型名与生成器版本，不含时间戳（确定性 FR-007）。

## 标识符映射规则

| 源标识符 | C++ 标识符 |
|----------|------------|
| 普通名 `x` | `x` |
| 与 C++/运行时保留字冲突 `switch` | `switch_` （旁注 `// source: switch`）|
