# 契约: 诊断信息格式与错误码

## 文本格式（stderr）

```text
[<severity>] <file>:<line>:<col>: <message> [MCxxxx]
```

示例：
```text
[error] cooling.mo:5:9: 未声明的标识符 "kappa" [MC0102]
[error] cooling.mo:9:3: 代数环检测: x ↔ y [MC0303]
```

- severity ∈ {`error`, `warning`}；存在任一 error → exit 2。
- 行列号自 1 起，指向问题 token 起点（FR-006）。
- 同一编译过程按 (line, col) 升序输出全部可发现诊断。

## 错误码分配表（首期稳定）

| 码 | 类别 | 触发条件 |
|----|------|----------|
| MC0001 | 结构 | 文件为空或未包含模型声明 |
| MC0002 | 结构 | 单文件中出现多个模型声明 |
| MC0101 | 符号 | 标识符重复声明 |
| MC0102 | 符号 | 使用未声明标识符 |
| MC0103 | 符号 | constant 缺少初始化值 |
| MC0201 | 表达式 | 不支持的运算符/字面量类型 |
| MC0202 | 表达式 | 调用了白名单之外的函数 |
| MC0203 | 表达式 | der() 使用位置非法 |
| MC0301 | 方程 | 方程数 < 未知量数（欠定） |
| MC0302 | 方程 | 方程数 > 未知量数（超定） |
| MC0303 | 方程 | 代数环（循环代数依赖） |
| MC0304 | 初始化 | 状态量缺少 start 初值且未 fixed |
| MC0401 | 实验 | 缺少实验设置注释或字段非法 |
| MC0204 | 表达式 | if/elseif 条件非布尔表达式 |
| MC0205 | 表达式 | if 表达式分支类型不一致（数值 vs 布尔） |
| MC0305 | 方程 | 条件方程违反分支平衡（缺 else / 分支方程数≠1 / 分支 LHS 不同未知量） |
| MC0306 | 方程 | 条件方程缺 else 且条件非常量（预留码，本期不触发；语义见 spec 003 契约 §4） |
| MC9001 | 内部 | 编译器内部断言失败（应视为缺陷上报） |

新增错误码 MUST 追加于本表尾部，禁止复用已发布编号。
