# Feature Specification: 仿真结果图形化表示

**Feature Branch**: `002-simulation-plot`

**Created**: 2026-08-24

**Status**: Draft

**Input**: User description: "生成的仿真图形化表示"

## Clarifications

### Session 2026-08-24

- Q: 绘图功能应以什么形态提供给用户？ → A: 嵌入生成的仿真程序：通过可选运行开关触发，
  仿真结束时同时产出结果 CSV 与图像文件；零参数默认行为保持不变（仅 CSV）。
- Q: 启用绘图开关后，图像生成完毕如何呈现给用户？ → A: 仅保存图像文件并在结束摘要中
  打印其路径；不自动调用系统查看器。
- Q: 生成程序内嵌的绘图能力应如何满足其对图像生成的依赖？ → A: 运行时仅用语言标准库
  自绘 PNG，生成程序保持零第三方依赖。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一键将仿真结果转为轨迹图 (Priority: P1)

建模工程师以附加的绘图开关运行生成的仿真程序；
程序照常完成仿真并写出结果 CSV，同时生成一张包含全部变量
随时间变化曲线的图像文件。打开图像即可直观判断模型行为
（趋势、收敛、振荡等），无需编写任何绘图代码或额外工具。

**Why this priority**: 图形化是"看懂仿真"的最短路径；没有基础出图能力，筛选与美化都无意义。

**Independent Test**: 以绘图开关运行 Hello 生成的程序，确认 CSV 照常产出，
且同目录新增图像文件，其中 x 曲线与数据逐点一致（0→1 线性）。

**Acceptance Scenarios**:

1. **Given** 任意已生成的仿真程序，**When** 用户带绘图开关运行它，**Then**
   程序正常结束（退出码不变），在输出目录同时得到 CSV 与一张图像文件。
2. **Given** 生成的图像，**When** 用户查看，**Then** 横轴为 time、每个数据变量一条曲线，
   抽查首、中、末三点均与 CSV 数值一致，且图例可区分各变量。
3. **Given** 不带绘图开关的正常运行，**When** 程序结束，**Then**
   行为与从前完全一致：仅产出 CSV，无图像文件（001 契约不受影响）。

---

### User Story 2 - 选择变量与控制输出 (Priority: P2)

用户只关心部分变量时，可通过绘图开关的附加选项指定一个或多个列名，
仅绘制所选变量的曲线；亦可自定义输出图像文件名；
多变量绘制在同一张图中便于对比。

**Why this priority**: 在基础出图可用后，选择性绘制显著提升大模型场景下的可读性
（几十个变量的全量图无法阅读），是第二顺位的日常刚需。

**Independent Test**: 对含 3 个变量的模型分别以"全量绘图"与"仅选 1 列"开关运行，
核对后者图像中只有 1 条曲线且文件成功生成。

**Acceptance Scenarios**:

1. **Given** 含多个变量列的模型，**When** 用户以指定单一列名的绘图开关运行，**Then**
   图像仅含该变量的曲线，图例正确显示列名。
2. **Given** 用户以逗号分隔指定多个列名，**When** 绘图完成，**Then**
   所选列的曲线出现在同一张图中。
3. **Given** 用户指定的输出路径不存在的目录，**When** 提供合法路径选项，**Then**
   目录被创建并写入图像；路径非法时给出清晰错误。

---

### User Story 3 - 失败输入的清晰诊断 (Priority: P3)

当绘图开关被启用而内部数据异常（无数据行、非有限值占比异常等），
或用户给出的绘图选项非法（列名不存在、输出路径不可写）时，
程序仍正常完成仿真与 CSV 输出，但拒绝生成图像并以人可读的诊断说明原因；
主仿真流程的退出语义不受绘图失败影响。

**Why this priority**: 与主编译器一致的诊断体验是质量底线，
但其价值在绘图主干可用之后才显现。

**Independent Test**: 构造绘图选项非法的运行样例集，逐条核对诊断信息、
CSV 照常产出且无残缺图像文件。

**Acceptance Scenarios**:

1. **Given** 列筛选选项包含不存在的名字，**When** 带开关运行完成仿真，**Then**
   CSV 正常产出；打印列出可用列名的诊断；不产生图像文件。
2. **Given** 输出图像路径不可写（如目录权限不足），**When** 运行完成，**Then**
   打印含路径原因的诊断；CSV 不受影响。
3. **Given** 绘图成功，**When** 程序结束，**Then** 退出码与未开绘图时一致
   （绘图状态通过摘要行/诊断表达，不改变既有退出码契约）。

---

### Edge Cases

- 仅一个网格点（单行数据）：应绘出单点标记而非空白图或崩溃。
- 含非有限值（inf/nan）的数据列：跳过坏点继续绘制其余数据，并在摘要中提示跳过数量。
- 大数据量（≥10 万行）：绘图开启时总耗时仍在可用量级且图像文件大小合理（内部降采样）。
- 变量名包含特殊字符：图例显示原始列名，不得导致绘图失败。
- 所有变量均为常数的退化情形：仍能生成有效图像（水平线）。
- 绘图开关与发散退出（001 的 exit 3）叠加：以 CSV 契约为先，图像按当时已有数据处置或放弃，
  不得改变退出码。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 绘图能力 MUST 内嵌于生成的仿真程序：以可选运行开关触发；
  启用后仿真结束时在 CSV 同目录生成包含全部变量曲线的图像文件（横轴 time）；
  零参数默认行为 MUST 保持与 001 契约完全一致（仅输出 CSV，无图像、无交互提示）。
- **FR-002**: 用户 MUST 能通过附加选项自定义输出图像路径；
  未指定时默认为 `<模型名>_result.png`，与结果 CSV 同目录。
  绘图完成后程序 MUST 仅在结束摘要中打印图像文件路径，
  MUST NOT 自动调用任何系统查看器打开图像。
- **FR-003**: 用户 MUST 能通过逗号分隔的列名列表筛选要绘制的变量；
  多列同绘于一张图。
- **FR-004**: 生成图像 MUST 包含标题（默认为模型名）、坐标轴标签
  （横轴 time、纵轴变量值）以及每条曲线的图例。
- **FR-005**: 绘图相关的失败情形（选项非法、列名不存在、输出不可写、内部数据异常）
  MUST 产生人可读诊断且不留下残缺图像文件；
  同时 MUST NOT 改变 001 已定义的退出码语义（主仿真的成败判定与绘图无关）。
- **FR-006**: 相同输入与相同开关组合 MUST 产生逐字节相同的图像文件
  （确定性输出，无时间戳元数据）。
- **FR-007**: ≥10 万行数据时启用绘图 MUST 使总运行时间仍处于可用量级
  （相对纯 CSV 模式增加 ≤10 秒；允许内部降采样，曲线视觉形状必须保持）。
- **FR-008**: 非有限数据点 MUST 被跳过且不影响其余曲线绘制；
  结束摘要中报告跳过统计。
- **FR-009**: 绘图开关的全部功能（默认关闭、列筛选、默认命名、错误分支、降采样边界）
  MUST 具有自动化测试覆盖。
- **FR-010**: 绘图实现 MUST 仅使用语言标准库在运行时内完成（含 PNG 编码）；
  生成的仿真程序 MUST 保持零第三方依赖，不得引入任何图像处理/绘图库。

### Key Entities *(include if feature involves data)*

- **内部结果数据**: 仿真循环产出的时间网格与各变量取值（与落盘 CSV 同源同 schema）；
  绘图的直接数据来源。
- **绘图请求**: 运行开关及其选项（可选列子集、可选输出路径）；决定是否出图及画什么。
- **图像产物**: 单张位图文件；含标题、轴标签、图例、全部所选曲线。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 从运行仿真到看到图像的增量操作 ≤1 条命令，全程 ≤5 秒（≤1000 行 CSV）。
- **SC-002**: 抽查验证下，图像曲线与 CSV 数据点的一致率为 100%（首/中/末三点法）。
- **SC-003**: 100% 的绘图失败情形（选项错、列名错、路径不可写、数据异常）
  得到含原因的诊断，无残缺图像产物，且主仿真退出语义不受影响。
- **SC-004**: 20 万行 CSV 绘图 ≤10 秒且图像文件 ≤5 MB。
- **SC-005**: 新用户依据文档无需绘图背景知识即可完成首次出图（≤2 分钟）。

## Assumptions

- 输出格式首期固定为 PNG 位图；SVG/PDF 等矢量格式留待后续迭代。
- 本地生成，不依赖任何网络服务；绘图代码随运行时分发至生成程序，
  并遵循零第三方依赖政策（FR-010）。
- 配色、网格线、分辨率等美学细节采用默认值，不做定制接口（简单性优先）。
- 降采样策略属于实现决策（规划阶段确定），规格仅约束"视觉形状不变 + 性能达标"。
- 绘图数据直接来自仿真循环的内存结果，与落盘 CSV 同源同 schema。
