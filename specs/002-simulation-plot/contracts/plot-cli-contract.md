# 契约: 绘图运行开关（生成的仿真程序）

**稳定性**: 与 001 CLI 契约并列的用户可见接口；破坏性变更需评审升版。

## 参数

| 参数 | 形式 | 缺省 | 说明 |
|------|------|------|------|
| `--plot` | 布尔开关 | 关闭 | 启用绘图；零参数行为不变（FR-001） |
| `--plot-columns=<a,b,…>` | `=` 连接 | 全部变量列 | 逗号分隔列名；含未知名 → `[plot]` 诊断 + 放弃出图 |
| `--plot-output=<path>` | `=` 连接 | `<模型名>_result.png`（CSV 同目录） | 输出图像路径；父目录自动创建，失败则诊断 |

- 三个参数均为可选、顺序无关、可任意组合；不带 `--plot` 时其余两个被忽略
  （不报错——保持"未知参数忽略"的既有契约）。
- 参数解析在生成的 main() 内完成；解析不产生副作用。

## 结束摘要行（stdout）

```text
plot: <path>              # 出图成功
plot: skipped (<原因>)     # 启用但放弃：columns 无效 / 路径不可写 / 数据全坏 / 发散叠加
plot: off                 # 未启用（保持与旧版本输出兼容时此行省略亦可——见下）
```

**兼容性决定**: 为使零参数运行的 stdout 与 001 逐字节一致，
`plot: off` 行仅在 `--plot` 存在时才可能出现；
未启用时不打印任何 plot 行。

## 退出码

- 绘图成功/失败/关闭 **均不改变** 001 定义的退出码
 （0=成功；3=数值发散；绘图不参与成败判定）。
- 所有绘图诊断走 stderr，带 `[plot]` 前缀，人读格式。

## 图像文件命名与位置

- 缺省：CSV 所在目录下 `<模型名>_result.png`；
- 显式相对路径相对**进程当前工作目录**解析；
- 成功写出后原子替换已存在的同名文件（先写临时名再 rename，避免半成品）。
