# 契约: PNG 图像产物

适用于 `--plot` 产出的全部图像文件（FR-006 确定性、FR-010 零依赖实现）。

## 编码规格

| 项 | 值 |
|----|-----|
| 格式 | PNG (RFC 2083)，签名 `89 50 4E 47 0D 0A 1A 0A` |
| 尺寸 | 固定 960×540 px |
| 色型 | 真彩色 RGB，位深 8，非隔行 |
| 块布局 | IHDR → IDAT → IEND（无辅助块：**无 tEXt/tIME 等**，保障确定性） |
| zlib 流 | stored（未压缩）deflate 块 + Adler32；每行前置过滤字节 0x00 |
| 校验 | 每块 CRC32 由实现自算；可用任何标准工具校验 |

## 视觉版面

- 白色背景；黑色坐标轴与刻度文字；浅灰主网格线。
- 绘图区：边距 left=72 / right=24 / top=48 / bottom=44。
- 标题（2× 点阵字体）= 模型名；横轴标签 `time`；纵轴为数值刻度。
- 每变量一条折线，颜色取自固定 8 色调色板（按列声明序循环）；
  图例位于绘图区右上内侧：色块(10×7) + 列名原文。
- 非有限点剔除；单点序列绘制为 3×3 实心方块标记。

## 确定性

- 同一帧缓冲 → 逐字节相同的 PNG 文件；
- 不含时间戳、路径、软件名等任何可变元数据；
- 金样基线测试逐字节比对（tests/golden/hello_plot/）。

## 可校验性

任何标准 PNG 工具均可验证产物：
```bash
file <图像>.png                      # 识别为 PNG 960 x 540
python3 -c "import struct,zlib,sys; \
  d=open(sys.argv[1],'rb').read(); assert d[:8]==bytes.fromhex('89504e470d0a1a0a')" <图像>.png
```
